Only https addresses work here. A public repository needs nothing else.

The token is used for this fetch only. It is not saved, not shown again and not written to any log.

The fetch uses the remote's stored credentials, so only a project's owner can do this. {{if .PreProject}}You came from the Git page of {{.PreProject}}, whose remote has commits that project did not make.{{end}}

A folder is for a repository Scríobh pushed with a folder prefix: only that folder is imported.

Scríobh makes a shallow copy of one branch, reads only the Markdown text and the project file, and shows the proposed tree. A repository larger than {{.RepoMiB}} MB is refused. The limits are {{num .Caps.Markdown}} Markdown files, {{.Caps.FileMiB}} MiB for one file and {{.Caps.TotalMiB}} MiB of Markdown in all.

What is kept

The new project records the repository's address, the commit it was made from and a fingerprint of each file, as its source. A copy of the fetched repository is kept beside the project for about a month, for reference, and is then removed; the project itself is not touched when it goes.

Your imports

An import that is fetched but never applied is removed after a day. You can have five waiting at a time.
