HTML leaves out front matter, comments and private notes, and loads nothing from outside.

The notes you keep for yourself are left out unless you ask for them.
Text between %% marks stays out of an HTML export unless you ask for it. A Markdown export always keeps it, as stored.

The chosen wording is in the text either way. Keeping the other wordings means importing the file brings them back; leaving them out gives plain Markdown. This is for a Markdown export; an HTML export is always the chosen text.

Ghosted text is not counted, but it is part of the chapter, so an export keeps it, as stored (dimmed again when imported), unless you say otherwise.

A zip is the full copy that an import can restore, so it keeps everything unless you say otherwise. If a download leaves some out, it tells you how many.

The stash is never part of an export.

Every export is recorded with a manifest of the documents it held and their SHA-256 hashes. The zip carries that manifest as scriobh.json, so you can check a copy later.
