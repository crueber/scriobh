The fonts in this directory are embedded unmodified (the original files, byte for
byte) and are subset only inside the PDF files the program writes, which both
licences allow. They were taken from the LibreOffice 26.8 application bundle
(Contents/Resources/fonts/truetype), which ships them unchanged from upstream.
